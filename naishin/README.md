# 内申点チェック（大分260点・宮崎135点）スマホ用 Webアプリ

データ元：Googleスプレッドシート「内申点チェック（自動更新）」のタブ「中3」「中2」。

## 計算（大分）
- ① 中1学年末（65点）＝5教科の合計＋実技4教科の合計×2
- ② 中2学年末（65点）＝5教科の合計＋実技4教科の合計×2
- ③ 中3 2学期（130点）＝5教科の合計×2＋実技4教科の合計×4
- 中3：①②がない→「中1・中2が入力漏れ」。③がなく中3 1学期がある→1学期で計算して「仮」。中3の通知表がない→「中3が入力漏れ」。仮と中3入力漏れは③を仮入力して試せる。
- 中2：中1学年末がない→「中1学年末が入力漏れ」。ある→今の中2の評定（2学期、なければ1学期）のまま②③を迎えたときの見込み。②③を仮入力して試せる。
- 評定は1〜5だけを使う（空白・#N/A・-1 は未入力）。中高一貫校は外す。大分かどうかは中学校の列の先頭の市町村名で見分ける。

## ファイル
- `gas/Code.gs`：Apps Script の「コード.gs」に全文を貼る
- `gas/Index.html`：Apps Script の HTML ファイル「Index」に全文を貼る（`src/build.py` で作る。直接は直さない）
- `src/`：画面の部品（body.html・sp.css・extra.css・ui.js・boot.js・tentori.png）

## 設定
- タブ名を変えたら `Code.gs` の `GRADE_SHEETS` も変える。
- 「基準」タブ（見出し「高校名」「基準点」）の高校は、生徒の画面で選ぶと目標点に入る。行を足せばすぐ反映（新バージョン不要）。
- ログインは過去最高チェックのスマホ版と同じ形。「プロジェクトの設定」→「スクリプト プロパティ」に `SP_USER_＋ID` ＝「パスワード,教室」。
- デプロイ：種類「ウェブアプリ」、次のユーザーとして実行「自分」、アクセスできるユーザー「東セミ内の全員」。

## 宮崎（135点満点）
- ①中1学年末・②中2学年末・③中3 2学期とも、9教科の評定の合計（各45点）。
- 大分と同じアプリの中で、県を切り替えて見る（両方の生徒が見られる人だけ切り替えボタンが出る）。
- 志望校の基準点はタブ「基準（宮崎）」（見出し「高校名」「基準点」）。略し方は Code.gs の PREFS.宮崎.alias に足す。
