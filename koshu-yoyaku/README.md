# 講習 時間枠予約システム（高校準備講座 2026年度版）

Googleスプレッドシート＋Apps Script（Webアプリ）で動く、講習の時間枠予約ページです。
保護者はスマホで「会場 → 生徒情報 → 各タームの時間枠 → 確認」の順に申し込み、
申込シート・会場ごとのブース表・受付メールが自動で処理されます。

- 本番のスプレッドシート：[（新）高校準備講座の時間割（O専門館・M専門館・明野P）](https://docs.google.com/spreadsheets/d/1Zp_jU0aCZOZIEj2TvrLMprygp8wJmDN2uxlUEoa2ZPE/edit)
- 講師向けの使い方：[Googleドキュメント](https://docs.google.com/document/d/1Nm9NZ_VFg3ESzSUQ9WcWZrSXzj5CtsonIvUsuFwji0c/edit)（[docs/講師向け使い方まとめ.md](docs/講師向け使い方まとめ.md) にも同じ内容）
- 保護者向けの案内メール：[docs/保護者向け案内メール.txt](docs/保護者向け案内メール.txt)

## 仕組み（決まりごと）

- 教室・日程・時限・定員は、すべて「定員」シートから読み込む。
  1行目のG列から右、最初の空欄の列の手前までが会場（教室）。その右にメモを書くときは1列空ける。
- 「申込」シートは1人1行。氏名・メール・電話番号のうち **2つ以上が同じ** 申込は同じ人とみなし、前回の行を消して置き換える。
- 各時間枠は開始の **24時間前** で締切。締切を過ぎた枠は「受講確定」として変更時も自動で引き継ぐ。
- 申込・変更・「定員」シートの編集のたびに、会場ごとのブース表（`BOOTH_SHEETS`）を作り直す。
  席は4つごとに色分け、名前の横は通塾教室の略称（`shortRoom_`：Passion→P、東セミ〇〇→〇〇S、例外は `SHORT_ROOM_FIXED`）。
- 「名簿」シートにA〜E列（氏名・中学校・通塾教室・メール・電話）を貼ると、F列に申込あり／未申込が数式で出る（氏名・メール・電話番号のうち2つ以上が一致すれば申込あり）。

## 次の講習で使い回す手順

1. **スプレッドシートをコピーする**
   本番のスプレッドシートを開き「ファイル」→「コピーを作成」。Apps Script も一緒にコピーされる。
   コピーの「申込」シートは2行目から下を行ごと削除、「名簿」シートはA〜E列の2行目以下を消す。
2. **日程と会場を設定する**
   コピーの「拡張機能」→「Apps Script」を開く。`Setup.gs` がなければ「＋」→「スクリプト」で `Setup` を作り、`gas/Setup.gs` の中身を貼る。
   `Code.gs`・`index` もこのリポジトリの最新版に貼り替えておく。そのうえで `Setup.gs` の `COURSE` を書き換える。
   - `rooms`：会場名（予約ページのボタンになる）
   - `terms`：ターム名と期間（`from`〜`to`、年-月-日）。平日の開講時限がタームで違うときは `weekdayPeriods` を付ける
   - `periods`：時限と時間
   - `closedWeekdays` / `closedDays` / `closedSlots`：休みの曜日・日・コマ
   - `capacity`：定員の初期値の決め方
3. **会場が変わる場合は `Code.gs` も直す**
   - `BOOTH_SHEETS`：ブース表のシート名（`rooms` と同じ順番）
   - `PICK_PER_TERM`（1タームで選ぶ数）、`CLOSE_HOURS`（締切の時間）も必要なら変更
4. **`makeCapacitySheet` を実行する**
   関数の選択欄で `makeCapacitySheet` を選んで「▷ 実行」。「定員」シートとブース表が作り直される。
   そのあと「定員」シートで定員の数字を細かく調整してよい（ブース表に自動反映）。
   ※受付開始後は `makeCapacitySheet` を実行しない（定員の調整が消える）。
5. **画面の文言を確認する**（`gas/index.html`）
   講座名「高校準備講座」、写真の上の「HIGH SCHOOL PREP COURSE 2026」、「各タームで2つ（合計6枠）」、通塾教室の選択肢など。
   直すときは `tools/index.template.html` を直してから `python3 tools/build_index.py` で `gas/index.html` を作り直すと、写真も入ったまま更新できる。
6. **公開する**
   「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行するユーザー「自分」、アクセス「全員」。
   初回は権限確認で「詳細（Advanced）」→「（プロジェクト名）に移動」→ 許可。
   表示された `/exec` のURLを保護者向け案内メールに入れる。
7. **試しに申し込む**
   申込シート・ブース表・受付メールを確認し、同じ名前とメールでもう一度申し込んで変更も確認。最後にテストの行を行ごと削除し「予約管理」→「ブース表を更新」。

## コードを直したとき

Apps Script に貼り替えて保存したあと、「デプロイ」→「デプロイを管理」→ 鉛筆 →「新バージョン」→「デプロイ」。
（「新しいデプロイ」にするとURLが変わるので注意）

## 注意

- 個人のGmailで公開すると、ページ上部に「このアプリケーションは Google Apps Script のユーザーによって作成されたものです」と表示される（Google側の表示で、コードでは消せない）。
- 「定員」シートの数字には数字だけを入れる（「8名」は0扱い）。枠ID・日付・時限の列と1行目の会場名は変えない。
