# 高校準備講座 予約システム 使い方まとめ（講師用）

保護者は予約ページ（スマホ）から申し込みます。申込・変更のたびに、スプレッドシートの申込シートとブース表が自動で更新され、保護者に受付メールが届きます。**講師がシートに手入力する必要は基本的にありません。**

## 使うスプレッドシート

[（新）高校準備講座の時間割（O専門館・M専門館・明野P）](https://docs.google.com/spreadsheets/d/1Zp_jU0aCZOZIEj2TvrLMprygp8wJmDN2uxlUEoa2ZPE/edit)

| シート | 中身 | 講師が触るか |
|---|---|---|
| 定員 | 時間枠と定員の一覧（G列：大分駅／H列：わさだタウン／I列：明野P） | 定員の数字だけ変えてよい |
| 申込 | 申し込み1件＝1行（自動で書き込まれる） | 取り消しのときだけ行を削除 |
| O専門館／W専門館／明野P | 会場ごとのブース表（自動で作られる） | 見るだけ |
| 名簿 | 対象者の名簿と申込あり／未申込 | A〜E列に名簿を貼る |

## ブース表の見方

- 日付が横、時限が縦。時限ごとに定員の数だけ席が並びます。
- 名前の横は通塾教室の略称です（例：かず家S、滝尾SP、かず家P、わさだP+、鶴見丘P、一般生）。
- 席は4つごとに色分け（1〜4：黄／5〜8：緑／9〜12：青）。濃い色が空席、薄い色が申込済み。
- 灰色はその日にない席、薄い赤は定員オーバー（席の調整が必要）。

## 定員を変えたいとき

「定員」シートの数字を変えるだけで、ブース表と予約ページに自動で反映されます。

- 数字だけを入れてください（「8名」のように書くと0扱いになります）。
- 枠ID・日付・時限の列と、1行目の教室名は変えないでください。
- J列は空けておいてください。メモはK列より右に書きます。

## 申し込みを取り消したいとき

1. 「申込」シートで該当する行の行番号を右クリックし、「行を削除」（セルの中身だけ消すのはNG）。
2. メニュー「予約管理」→「ブース表を更新」。

## 保護者から日程変更の連絡があったとき

教室でシートを直さず、次のように案内してください。

> もう一度予約ページから、前回と同じお名前・メールアドレス・電話番号でお申し込みください。

- 前回の内容が表示され、変えたい枠だけ選び直せます。
- 前回の申込は自動で消え、ブース表も自動で更新されます。外した枠は他の人が申し込めるようになります。
- 開始まで24時間を切った枠は「受講確定」となり、変更できません。

## 未申込の家庭を調べたいとき（名簿シート）

1. 「名簿」シートのA〜E列（生徒氏名・中学校・お通いの教室・メール・電話番号）に名簿を貼り付けます（⌘＋Shift＋V で「値のみ貼り付け」）。
2. F列に「申込あり／未申込」、G列に申し込んだ会場が自動で出ます。I〜J列に人数のまとめが出ます。
3. 未申込だけ見るには、F1を選んで「データ」→「フィルタを作成」→ F列の ▼ で「未申込」だけにチェック。

氏名（スペースは無視）が同じ、またはメールアドレスが同じ申込があれば「申込あり」になります。

## 困ったとき

| こんなとき | こうする |
|---|---|
| ブース表が古いまま | メニュー「予約管理」→「ブース表を更新」 |
| 「予約管理」メニューが見えない | スプレッドシートを再読み込みする |
| 保護者に受付メールが届かない | 迷惑メールフォルダの確認を案内する |
| 予約ページの表示や動きがおかしい | 【担当者名】まで連絡 |
